# 故障排查

本文按症状组织。先在界面上确认具体错误文案，再按对应章节处理。

## 连接

### 一直停在“连接中”

1. 确认主机与端口可达：`nc -vz <host> <port>`。
2. 确认协议选择正确。SSH 默认 22，Telnet 23，VNC 5900，RDP 3389。
3. 检查跳板链：每一跳都要可达，且认证方式独立有效。
4. 查看连接错误详情中的阶段（TCP、握手、认证、PTY）。
5. 若使用 `Auto` 认证，临时改为单一方式，排除某一方式超时导致整体等待。

### “主机密钥已变化”

说明同一主机返回了不同的密钥。可能是服务器重装、容器重建或中间人攻击。

1. 在设置中查看旧指纹与新指纹。
2. 通过带外渠道核对服务器指纹。
3. 确认无误后移除旧记录，重新连接并确认新指纹。
4. 无法核实时不要继续连接。

### 认证失败

- **Password**：确认密码来源是“表单”还是“本地命令”；本地命令失败时错误可能出现在
  子进程 stderr，而不是网络层。
- **Private key**：确认路径可读、格式受支持（OpenSSH/PEM/PPK）、口令正确。
  粘贴内容优先于路径，检查是否残留了旧内容。
- **SSH Agent**：确认 `SSH_AUTH_SOCK` 指向正确 socket，且 key 已加入。
- **键盘交互/2FA**：确认验证码未过期；设备时间偏差会导致 TOTP 失败。
- **只读连接**：只读不影响登录，但会拒绝写操作与 sudo。

### 连接后立即断开

- 服务器可能限制并发会话或空闲时间；启用连接保活。
- 检查远程 shell 启动脚本是否立即退出。
- 查看远端 `sshd` 日志与账号的 `nologin`/`ForceCommand` 配置。

## 终端

### 画面停止更新，但输入有反应

说明 transport 仍活着，输出帧出现缺口且未补齐。RemoteX 会在缓冲溢出时主动请求回放；
若仍复现：

1. 切换标签或重新打开会话，观察是否恢复。
2. 查看是否在极高吞吐（`yes`、大日志 `cat`）下出现。
3. 记录会话 id、发生时间与命令，提交问题时附上。

### 输入没有反应

- 标签可能已断线；查看状态事件与错误提示。
- 串口在文件上传期间会拒绝普通输入，等待上传结束。
- 只读连接不限制输入，但远端可能因权限拒绝命令。

### 中文或宽字符错位

- 确认终端使用 Unicode 11 宽度表。
- 远端 locale 需要支持 UTF-8，例如 `LANG=en_US.UTF-8`。
- 某些程序输出 GBK；可在连接设置中调整编码或使用 `iconv`。

### 复制/粘贴异常

- 终端粘贴使用宿主剪贴板权限。
- 大段粘贴会走 bracketed paste；若远端程序不支持，可能出现额外字符。
- SFTP 的文件粘贴依赖宿主/浏览器暴露原生 `paste` 文件事件；不支持时使用上传按钮或拖放。

## SFTP 与传输

### 上传/下载很慢

- 查看传输面板的速度与并发数；并发过高可能互相争抢带宽。
- 检查是否启用了压缩；已压缩文件（图片、视频、zip）压缩收益低。
- 高延迟链路上小文件多时，目录传输会明显慢于单文件。
- 服务端磁盘或 CPU 饱和也会成为瓶颈。

### 传输中断后无法续传

- 续传要求远端仍保留临时文件或已写入部分。
- 若目标文件被外部修改，续传会被拒绝，需要重新开始。
- 查看传输历史中的错误类型。

### 删除很慢

- 多选删除会先生成计划，再按批执行；目录越大，计划阶段越久。
- 大量小文件受 SFTP 往返限制，属于协议开销。
- 确认没有其他传输占满连接。

### 传输历史看不到以前的记录

- 历史按连接隔离；切换到对应连接查看。
- 全局只保留最近 200 条终态记录。
- 清空操作只影响当前连接。
- 旧版本留下的无连接归属记录会被隐藏。

### 文件权限或属主不对

- SFTP 上传按远端 umask 创建文件。
- 需要提权写入时使用 sudo 文件操作，而不是普通 SFTP。
- 检查远端目录的 setgid 与 ACL。

## 远程桌面

### VNC 黑屏或画面冻结

- 确认 VNC 服务端支持所选编码。
- 调整窗口尺寸会请求服务器 resize；部分服务器不支持。
- 查看会话状态事件中的错误。

### RDP 无法连接

- 确认服务器允许 NLA/TLS 与所选认证方式。
- 证书策略过严会拒绝自签名证书。
- RDP 不支持音频与磁盘重定向；相关设置不会生效。

## 端口转发

- 本地端口被占用时启动失败；换端口或先释放。
- 远程转发需要服务器允许 `AllowTcpForwarding`。
- 动态转发是 SOCKS5，不是 HTTP 代理；客户端需按 SOCKS5 配置。
- 转发随所属连接关闭而停止；需要常驻时使用“连接打开时自动启动”。

## Docker

- 远程 Docker 需要登录用户有 docker 权限，或配置 sudo。
- 容器终端打不开时检查容器是否仍在运行。
- 日志跟随会占用连接；大量日志时降低刷新频率或使用下载。
- 本地 Docker 不可用时检查 Docker Desktop/daemon 是否运行。

## 录制

### 录制面板为空

- 确认录制已开始且停止后写入完成。
- 点击刷新。
- 检查录制目录权限与磁盘空间。

### 回放不完整

- 录制文件可能被截断；查看文件大小与最后事件时间。
- GIF 导出有帧数上限，长录制会被抽帧；需要完整内容时导出转录文本。

### 录制中是否包含鼠标和光标

不包含。录制只保存终端输入与输出，不采集系统指针、光标坐标或剪贴板。

## MCP

### `dbx_call_plugin_tool` 找不到工具

- 先调用 `dbx_list_plugin_tools` 确认插件已加载。
- 确认插件版本包含 MCP 工具（16 个）。
- 确认 `pluginId` 与安装清单一致。

### 独立 stdio 模式连不上

- 确认二进制路径可执行：`dbx-plugin-sshx --mcp`。
- 客户端配置的 `command` 必须是绝对路径。
- 检查客户端是否按换行分隔 JSON-RPC 发送。
- 数据目录不可写时，Known Hosts 与 MCP 设置无法保存。

### 连接 id 无法解析

- 先调用 `ssh_list_connections`。
- 使用 `connectionName` 时，若重名需补 `host`/`port`/`username`。
- 桥不可用时使用内联凭据，但要知道凭据会进入工具参数与模型上下文。

### 工具被拒绝

按错误文案区分：

- **只读连接**：连接勾选了只读，写操作与 sudo 被拒绝。
- **命令白名单**：命令不在允许列表。
- **危险命令**：需要 `confirmDestructive: true`。
- **路径约束**：本地路径不在允许目录。
- **权限档**：`execPermissionMode` 或 `connectionScope` 拒绝。

## 构建

### `dbx-plugin: command not found`

安装 `@dbx-app/plugin-cli`，或把其可执行文件加入 `PATH`。

### 前端构建失败

- 确认 Node 与 pnpm 版本符合 `.tool-versions`。
- 删除 `frontend/node_modules` 后重新 `pnpm install --frozen-lockfile`。
- 类型错误先跑 `pnpm --dir frontend typecheck` 定位。

### Rust 构建失败

- 确认工具链为 `1.97.1`。
- Linux 串口依赖需要 `libudev-dev`。
- 某些环境缺少 `librustc_driver` 时 `cargo fmt` 无法启动；这是本机 rustfmt 安装问题。
- 打包时 SDK 路径由 `scripts/lib/sdk_root_shim.sh` 固定，不要手动 unset
  `DBX_PLUGIN_SDK_ROOT`。

### 测试全部 SKIP

live smoke 需要 Docker 与测试容器。设置 `DBX_SMOKE_STRICT=1` 可让缺失环境直接失败，
避免把跳过误认为通过。

## 收集诊断信息

提交问题时请提供：

- RemoteX 版本与 DBX 版本
- 操作系统与架构
- 协议（SSH/Telnet/VNC/RDP/Serial/RemoteX）
- 复现步骤与预期/实际结果
- 错误文案与相关面板截图
- 终端相关：会话 id、发生时间、当时执行的命令
- 传输相关：方向、文件大小、错误类型

请勿提交密码、私钥、TOTP 种子、完整主机地址或含敏感内容的录制文件。
