# 快速开始

本文从安装开始，带你完成第一条连接、第一次文件传输和第一次录制。

## 1. 安装

### 从发布包安装

1. 打开 [GitHub Releases](https://github.com/apolloqi123/dbx-plugin-remotex/releases)。
2. 下载与操作系统、CPU 架构匹配的 `.dbxp` 文件。
3. 在 DBX 插件中心选择“从本地安装”，选中该文件。
4. 刷新插件或重启 DBX。

安装后，新建连接页面会出现 **RemoteX** 入口；命令面板中会出现 **RemoteX** 命令，
用于直接打开本机终端。

### 从源码构建

需要：

- Rust `1.97.1`（见 `.tool-versions`）
- Node.js `26.12.1`
- pnpm `11.24.0`
- `dbx-plugin` CLI（打包 `.dbxp` 时需要）

```bash
pnpm --dir frontend install
cargo build --release --manifest-path backend/Cargo.toml
scripts/build.sh
```

产物在 `dist/`。完整说明见 [开发指南](development.zh-CN.md)。

## 2. 建立第一条连接

1. 在 DBX 中新建连接，选择 **RemoteX**。
2. 在表单内选择协议：**SSH**、**Telnet**、**VNC**、**RDP**、**Serial** 或 **RemoteX**。
3. 填写连接名。SSH/Telnet/VNC/RDP 还需要主机与端口；串口选择设备；RemoteX 不需要网络地址。
4. 选择认证方式：
   - **Password**：直接输入密码。
   - **Private key**：填写私钥路径，或粘贴私钥内容。
   - **Private key, then password**：私钥认证后再输入密码。
   - **SSH Agent**：使用 `SSH_AUTH_SOCK` 或 Windows Pageant。
   - **Auto**：按密码、私钥、键盘交互、Agent 的顺序尝试。
   - **No authentication**：明确不需要认证时使用。
5. 需要跳板机时配置 ProxyJump（最多三跳）。
6. 保存并打开连接。

首次连接到未知主机时，RemoteX 会要求确认主机密钥。确认后写入插件自己的
Known Hosts 存储；之后密钥变化会被拒绝。

### 密码来源

SSH 连接可以选择密码来源：

- **Enter in this form**：密码保存在宿主 secret store。
- **Local command**：连接时执行本地命令，取 stdout 去掉末尾一个换行作为密码。
  命令以当前用户权限运行。

### 双因素认证

支持 TOTP 与键盘交互。连接时弹出的验证码只用于本次认证，不会保存。可在 OTP
管理页绑定、导入二维码或生成当前验证码。

## 3. 认识工作台

打开连接后，工作台由以下区域组成：

```
┌─────────────────────────────────────────────────────────────┐
│ 标签栏：连接名 / 会话状态 / 新建与复制会话                  │
├─────────────────────────────────────┬───────────────────────┤
│ 终端                                │ SFTP                  │
│ - 多标签、分屏                      │ - 目录树与文件列表    │
│ - 搜索、回放、复制模式              │ - 预览、编辑、上传    │
│ - 快速命令、高亮、批量输入          │ - 书签、磁盘用量      │
├─────────────────────────────────────┴───────────────────────┤
│ 工具条：指标 / 转发 / 录制 / Docker / 设置                  │
└─────────────────────────────────────────────────────────────┘
```

常用入口：

| 入口 | 作用 |
| --- | --- |
| **复制会话** | 在这条已认证 SSH 连接上打开独立 PTY，不重新认证 |
| **新建会话** | 建立全新连接并重新认证 |
| **SFTP** | 浏览与传输文件；支持拖放与剪贴板文件粘贴 |
| **Port forwards** | 管理本地、远程与 SOCKS5 转发 |
| **Docker** | 容器列表、日志、统计、终端与文件 |
| **服务器指标** | CPU、内存、网络、磁盘、进程 |
| **录制** | 开始/停止录制，打开录制记录面板 |
| **RemoteX** | 打开本机登录 Shell |

## 4. 第一次文件传输

1. 打开右侧 SFTP 面板。
2. 进入目标目录。
3. 从文件管理器拖入文件，或复制本地文件后在 SFTP 面板按 `Ctrl/Cmd+V`。
4. 在传输面板查看进度；可取消，可重试。
5. 大文件中断后，重新发起时会提示是否续传。

删除文件或文件夹时，确认框会先列出待删项。多选删除会生成删除计划并批量执行。

## 5. 第一次录制

1. 点击工具栏的录制入口。
2. 在录制菜单中选择“开始录制”。开始前有 3 秒倒计时，可取消。
3. 录制中面板显示时长；点击“停止录制”结束。
4. 打开“录制记录”：
   - `Enter` 打开回放
   - `Esc` 关闭面板
   - 可导出 GIF 或转录文本
   - 可在文件夹中显示录制文件

录制文件是 asciicast v2 `.cast`，默认保存在插件数据目录。录制不采集系统鼠标
指针、光标坐标或剪贴板内容。

## 6. 导入已有连接

RemoteX 支持从常见客户端导入连接：

- OpenSSH `~/.ssh/config`
- Xshell
- SecureCRT
- Termius
- MobaXterm
- FinalShell
- Electerm
- WindTerm

导入流程为“选择来源 → 预览 → 确认”。预览阶段可以取消；导入不会覆盖同 id 的
现有连接，冲突项会在预览中列出。

## 7. 数据放在哪里

| 内容 | 位置 |
| --- | --- |
| 连接元数据与密钥 | DBX 宿主存储（secret binding） |
| 插件设置 | 插件数据目录下的偏好文件 |
| Known Hosts | 插件数据目录下的独立 known_hosts 文件 |
| 录制文件 | 插件数据目录下的录制目录 |
| 传输历史 | 插件数据目录下的历史文件，按连接 id 隔离 |
| MCP 设置 | 插件数据目录下的 `mcp-settings.json` |

可用 `DBX_PLUGIN_DATA_DIR` 重定向插件数据目录，常用于测试与便携部署。
